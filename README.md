# 1. Introduction: 
SQL (Structured Query Language) is a standardized language for all relational databases management systems. Every RDBMS, such as MySQL and PostgreSQL, uses SQL as its primary language and add extra specific features on it. There are 5 main categories of SQL Commands: 

| Category | Full Form                    | Purpose                              |
| -------- | ---------------------------- | ------------------------------------ |
| DDL      | Data Definition Language     | Define and modify database structure |
| DML      | Data Manipulation Language   | Insert, update, and delete data      |
| DQL      | Data Query Language          | Retrieve data                        |
| DCL      | Data Control Language        | Control permissions and access       |
| TCL      | Transaction Control Language | Manage transactions                  |

![image](./assets/images/introduction/sql_commands.webp)

Note: SQL is a query language and cannot run independently. It requires a DBMS specifically RDBMS, such as MySQL or PostgreSQL etc to run.
