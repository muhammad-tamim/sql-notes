- ON DELETE options:
  - ON DELETE CASCADE: If parent is deleted → automatically delete all related child rows

 ```sql
 user_id INT REFERENCES users(id)  ON DELETE CASCADE
 ```
  - ON DELETE SET NULL: If parent is deleted → keep child rows, but set foreign key to NULL (column must allow NULL)

 ```sql
 user_id INT REFERENCES users(id) ON DELETE SET NULL
 ```
  - ON DELETE RESTRICT: Prevent deleting the parent row if any child rows reference it

 ```sql
 user_id INT REFERENCES users(id) ON DELETE RESTRICT
 ```
